 HelpMate — Database Schema (HelpMate schema in Supabase)
 Last updated: 2026-04-20
 Changes from original:
   - Removed xp_next, level_name, selected_rod, selected_bait from users (moved to dedicated tables)
   - Added message_privacy, total_reviews to users
   - level in users is now FK → levels
   - password_hash removed (handled by Supabase Auth)
   - friendships: renamed requester_id → user_id, addressee_id → friend_id
   - review_tags split into master list + review_selected_tags junction table
   - fisher_rods renamed to user_rods (added is_selected column)
   - fisher_baits renamed to user_baits
   - Added: levels, review_selected_tags
